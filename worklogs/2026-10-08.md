# Neovim Tutorial
- :setlocal winfixheight = lock this window's size! Good for my worklog.md
- ctrl + <page up> = next tab
- ctrl + <page down> = previous tab
- [["_dP]] = paste over selection without losing yanked text
    - [[ ... ]] = two nested square brackets means raw multiline string literal
    - "_ = black hole register! Anything yanked/deleted into it disappears!
    - "_d = delete selection and don't add to any register
    - P = paste selection before current cursor position

- ":m '>+1<cr>gv=gv"
1. Press <M-Down>  ──>  2. Execute :m '>+1  ──>  3. Press gv  ──>  4. Press =  ──>  5. Press gv
(Triggers map)          (Moves lines down)       (Reselects)       (Re-indents)    (Keeps selection active)

- Note: "<cmd>" and ":" in keymappings are NOT the same thing!!!
    - ":" = simulates you literally typing a :command in the Vim command line
    - "<cmd>" = executes command in background, no change to mode or buffer

- mz = mark current cursor location as "mark z"
- `z = jump to "mark z"
